# `funkin` module

Module for [`funkin_godot`](https://github.com/cherrythecool/funkin_godot) that ports the base game of [Friday Night Funkin'](https://github.com/FunkinCrew/Funkin)
to Funkin' Godot, for use as to either get a feel for the engine or have a better real-world reference for how you can use it.
